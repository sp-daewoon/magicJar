# 샘플: AI 프리셋 추천 (preset-recommend)

> 엔드포인트: `POST /api/strategy-research/ai-discovery/presets/recommend`
> 메타 프롬프트: `StrategyResearchAiDiscoveryService.buildPresetRecommendPrompt()`
> 본 문서는 메타 프롬프트가 조립하는 컨텍스트 구조와 기대 출력을 보여주는 예시다. 실제 호출 시 provider/generatedAt 은 런타임 값.

---

## 시나리오 A — hint 없음 (기본 3건, 기존 3 프리셋 차별화 요구)

### 요청
```json
{ "userId": "74683223", "count": 3 }
```

### 메타 프롬프트(요지 — 실제는 풀텍스트 조합)
- 역할: magicJar 종목 발굴 프리셋 설계 전문가, 프리셋=검증용 후보 가설 템플릿
- core wrapper 풀텍스트(DB 권위) 주입
- 기존 프리셋: 단기 거래대금 폭발 / 오더블록 지지 후보 / 섹터 순환매 대기 (label+description+promptText)
- 시스템 능력: candle 13종(1m~1y), 지표 82종(추세·모멘텀·거래량·변동성·오실레이터), 스마트머니=FVG·오더블록·스윙
- hint: 없음 → 시장 보편 + 기존과 차별화 지시

## 에러 케이스

| 상황 | HTTP | 메시지 |
|---|---|---|
| Claude CLI 타임아웃 | 504 | Claude CLI 응답 시간이 초과되었습니다. |
| 브릿지 429 | 429 | Claude 브릿지 호출 실패: ... |
| JSON 파싱 실패 | 503 | Claude 추천 JSON 파싱 실패: ... |
| 사용 가능한 item 0건 | 503 | Claude 응답에서 추천 프리셋을 읽지 못했습니다. |
| count=0 또는 6 | 400 | bean validation (@Min(1)@Max(5)) |

mock 합성은 하지 않는다. 실패 시 위 5xx 를 그대로 frontend 에 전달한다(기존 discovery 패턴 동일).
