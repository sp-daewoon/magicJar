★ 핵심 결론 (1줄)
W4(AI·MCP)는 옵션입니다. 다만 T-MCP는 사용자 명시 미래 비전이라 "옵션이지만 진행 의미 있는 트랙". W5도 마무리 트랙. 다음 1순위는 W4가 아니라 W3 잔여(§40 T-SIG, §43 T-O) 마감입니다.

W4 직행 시 prereq 위반 risk

T-AI의 PromptBuilder가 "시그널·룰엔진 결과·매매일지" 컨텍스트를 의존하는데, T-SIG·T-O 미완성이면 컨텍스트 데이터 0 → AI 분석이 빈 그릇이 됩니다. ADR 0026 §38 "T-AI prompt 컨텍스트 뉴스 명시" 정합도 T-NEWS 영속만으로는 부족합니다.

최고 관리자님께 — 요약

  • W4는 옵션입니다. T-MCP만 "옵션이지만 미래 비전"으로 진행 의미가 있습니다
  • W5도 마무리 트랙이며, 그 중 T-LWC는 frontend 단독이라 W4와 병렬 가능합니다
  • 코드 영향이 큰 모듈: W4 → consumer/(LLM adapter 3종) + frontend/(AiCard) / W5 → frontend/ 단독
  • 백로그 28건 중: MUST 3 / SHOULD 9 / COULD 16
  • 1순위 권장: W4 직행보다 §40 T-SIG + §43 T-O 사용자 결정으로 W3 본체 종착부터
