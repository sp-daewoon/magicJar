2. 왜 사고 / 왜 파는가 — 전략 정의

전략빌더가 strategy.dsl_entry / dsl_exit 텍스트 DSL로 저장. 매 1분봉 마감 시 평가됩니다.

매수조건 (dsl_entry)

low <= ma(10) * 1.002 AND close >= ma(10)

→ 저가가 10분 이동평균선의 0.2% 이내까지 닿고(눌림목 터치), 동시에 종가는 10분선 위에서 마감하면 매수. 즉 "이평선을 찍고 다시 올라선 지지 확인 매수".

매도조건 (dsl_exit)

close < ma(10)

→ 종가가 10분선 아래로 떨어지면 청산. 추세가 깨졌다고 보고 보유분을 정리.

이 전략의 구조적 특성: 매수조건은 "이평선 위에 있으면" 계속 참이 되기 쉬워 여러 분봉 연속 매수(누적)가 일어나고, 매도조건은 "이평선 이탈"이라 한 번에 전량 청산됩니다. 사용자가 본 "매수만 하다 나중에 매도까지 있더라"가 바로 이 누적매수 → 전량매도 패턴입니다.

4. 왜 매번 "3주"인가 — 포지션 사이징 계산

매수 수량은 고정값이 아니라 risk_config + 현재가로 매번 계산됩니다. 코드: resolveOrderQuantity() (consumer · SignalGeneratedKafkaListener).

계좌 리스크 설정
user 74683223 · risk_config
최대 포지션(절대)
1,000,000원 max_position_abs
최대 포지션(비율)
10% max_position_pct
삼성전자 현재가
약 314,000원 시그널 시점 종가
# 매수 예산 = 비율한도와 절대한도 중 작은 값
budget = min( 자본금 × 10% , 1,000,000원 ) = 1,000,000원

# 수량 = 예산 ÷ 현재가 (소수점 버림, 최소 1주)
qty = floor( 1,000,000 ÷ 314,000 ) = floor(3.18) = 3주

→ 삼성전자가 31만원대를 유지하는 한 매수는 항상 3주 고정. 만약 가격이 더 높았다면 2주, 더 쌌다면 더 많이 샀을 것입니다. 매도는 사이징을 거치지 않고 "현재 보유 전량"을 그대로 주문합니다.

6. 리스크 게이트가 막은 13건 — 자동매매는 왜 멈췄나

시그널이 생성돼도 리스크 게이트(STEP 2)에서 막히면 주문이 나가지 않고 risk_event에 기록됩니다.

차단 규칙건수해당 시각사유
SELL_WITHOUT_POSITION813:47, 13:48, 14:07, 14:37~14:41 직전 매도로 보유가 0이 됐는데 다음 분봉도 종가<10분선이라 SELL 신호가 또 떴음 → 팔 물량이 없어 차단
TRADE_FREQUENCY_DAY514:43 ~ 14:47 "Strategy daily trade count 50 >= limit 50" — 50번째 주문으로 일일 거래 한도 도달 → 이후 모든 신호(BUY·SELL) 차단
자동매매가 멈춘 진짜 이유: 매분 3주씩 사들이느라 주문 건수가 빠르게 쌓여 오후 2시 43분에 일일 50건 한도에 도달했습니다. 이 안전장치(risk_config.trade_freq_per_day=50)가 발동하면서 14:42에 산 마지막 3주를 팔지 못한 채 자동매매가 종료됐고, 그래서 최종 잔량 3주가 남았습니다. (그 직전 14:33~14:35에는 모의계좌 현금이 바닥나 KIS가 "주문가능금액 부족"으로 거부한 매수 3건도 있었습니다.)

7. 주문 1건의 실제 흐름 (심층 예시)

예시 A — 매수: 시그널 #10 → 주문 #23 (3주)

signal #10 BUY @13:38 close 314,250 → risk: ALLOWED → qty = 1,000,000÷314,250 = 3주 → order_request #23 REQUESTED → KIS 체결통보 (2건 분할) → 2주@314,250 + 1주@314,250 = FILLED

한 주문이 KIS에서 2건으로 분할 체결(2주 + 1주)되어 order_execution 2행이 생성됐습니다. 누적 체결량 3 = 주문량 3 이 되는 순간 주문 상태가 FILLED로 바뀌고 포지션이 갱신됩니다.

예시 B — 매도: 시그널 #50 → 주문 #58 (보유 전량 24주)

signal #50 SELL @14:18 close 314,500 → risk: ALLOWED → qty = 보유 전량 24주 → order_request #58 REQUESTED → KIS 체결통보 (8건 분할) → 24주 분할 체결 → FILLED

매도는 사이징 계산 없이 그 시점 보유 24주를 통째로 주문했고, KIS가 시장 호가에 맞춰 5주·1주·9주·1주·1주·2주·2주·3주 등 8건으로 쪼개 체결했습니다(313,500~315,000원). 매도 수량(24)이 사이클 6의 누적 매수량과 정확히 일치합니다.

8. 종합 — 무슨 일이 일어났나

  • 전략은 의도대로 "10분선 터치 후 지지" 매수 / "10분선 이탈" 매도를 정확히 실행했습니다.
  • 매수는 매번 예산 100만원 ÷ 현재가 ≈ 3주로 계산됐고, 조건이 연속 충족되어 매분 누적 매수됐습니다.
  • 매도는 그때까지 쌓인 보유 전량을 한 번에 청산 — 7개 사이클 동안 매수 120주 / 매도 118주.
  • 총 체결액: 매수 37,750,499원 · 매도 37,139,000원 (모의 가격이 313~318k에서 진동 → 거의 본전 수준의 단타 회전).
  • 오후 2시 43분 일일 거래 50건 한도에 걸려 자동매매가 종료, 마지막 매수 3주(@316,750)가 잔량으로 남음.
