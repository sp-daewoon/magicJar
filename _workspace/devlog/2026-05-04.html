3. Kafka 토픽·데이터 흐름 변경

candle.minute.aggregated.v1 (신규)

  • producer: consumer TickToMinuteAggregator (KIS WS tick → 1분 boundary OHLCV 합성)
  • producer: pyworker yfinance backfill 결과 (Yahoo Finance 30일치 1분봉)
  • consumer: api CandleMinuteEventListener → DB INSERT (interval=M1)
  • idempotent: PRIMARY KEY (code, interval, open_time) UNIQUE 활용

분봉 source 전환 (KIS REST → yfinance)

  • KIS FHKST03010200 = "당일 분봉 전용" — 과거 backfill 불가능
  • yfinance: 1m=30일·5m=60일·30m=730일·1h=2년 (실측 검증)
  • 한국 종목 .KS suffix (KOSPI·KOSDAQ 둘 다 작동)
  • cold-start: 신규 종목 첫 진입 시 자동 trigger (CandleQueryService → CandleCacheService → pyworker)

실시간 시세 (장중)

  • KIS WS H0STCNT0 체결 통보 → consumer aggregator → market.tick.v1 publish
  • 1분 boundary 진입 시 → candle.minute.aggregated.v1 발사
  • 5분 timeout — 메모리 bucket 자동 flush + 제거

이슈·복구

  • 토큰 한도 hit 다수 — sub-agent 12:20am KST 리셋 대기. 메인 세션 takeover (PR #114 backend·#115 frontend 작업 마무리)
  • worktree leak 누적 — 매 sub-agent 종료 후 정리 의무 (memory feedback_worktree_cleanup.md). lock 해제 + force remove + branch -D + orphan 빈 디렉토리 청소
  • 키 정책 흔들림 — DB 이전 시도(V21 plan) 폐기, .env 유지 결정. 사용자: "내가 직접 설치해줄거라서 큰 걱정은 안해도될거같아"
  • data 조회 = 항상 실전 키 정책 명시화 — 모의 키는 주문에만 사용. 모의/실전 분리는 주문 path만 의미
  • 5/1 휴장일 분봉 데이터 — V8 시드 mock 잔재. yfinance는 정직(KRX 휴장 응답 X). DELETE 360 row로 정정
  • KIS_API_FAILED EGW00002 (403) — 사용자 IP가 KIS 화이트리스트 미등록. 사용자 액션 필요 (https://apiportal.koreainvestment.com)
  • 로그 정책 — TRACE 금지·INFO 최소·Kafka WARN 억제. 사용자 정책 명시
  • logback %n 줄바꿈 회귀 — CONSOLE_TEXT appender springProfile 블록 외부로 이동 + charset UTF-8 명시
  • KIS endpoint 회귀 진단 — 정확한 endpoint는 search-stock-info. inquire-stock-info(잘못)·EGW00002 IP 추정(잘못) 둘 다 사용자 안내로 정정. CTPF1002R + PDNO=code&PRDT_TYPE_CD=300이 정확
  • DART corp_code XML regex 버그 — <corp> 태그 잘못, 실제 <list> 사용. 0건 파싱 → 모든 종목 lookup fail. PR #125에서 fix + 테스트 3건 추가
  • KIS·DART 통합 완료 — 005930 종목상세에 시총 1,289조·외국인 49.24%·매출 333조·PER 33.59·업종 "전기·전자" 모두 정상 응답
