4. 트러블슈팅 / 자율 결정

  • RMap.isEmpty — Redisson Java API에서 .isEmpty property가 아니라 함수 isEmpty(). 컴파일 에러 → 즉시 수정.
  • KisHttpSession 토큰 흡수 보류 — 1번 트랙 dogfooding 영향이 큰 영역(RealKisOrderAdapter·KisHashKeyClient가 executeWithRetry 메서드 의존). 본 사이클은 RestClient·executeWithRetry 패턴 보존 + 토큰 부분만 후속 사이클에서 흡수. spec §13-1 단계적 위임 옵션 채택. 자율 결정.
  • consumer KisProperties prefix 변경 보류 — @ConfigurationProperties(prefix="kis")는 1번 트랙 산출물 영향. 신규 통합 path(magicjar.kis.*)와 병기 + 환경변수 fallback 체인으로 호환.
  • Redis 어댑터 default OFF — PR3·PR4·PR5 모두 matchIfMissing=false + InMemory는 matchIfMissing=true. 사용자 docker rebuild 후 MAGICJAR_KIS_REDIS_TOKEN_ENABLED=true 추가 시 자동 전환. 회귀 0 보장.
