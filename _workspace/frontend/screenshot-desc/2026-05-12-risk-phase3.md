## Screen 1 — /risk-config (리스크 설정 페이지)

- 페이지 타이틀 "리스크 설정" + 설명 문구 표시
- A 섹션: 포지션 한도 (절대 한도 원화 입력 필드 + 비율 한도 1~100% 슬라이더)
- B 섹션: 일일 손실 한도 DLL (전역 DLL 입력 + 절대/비율 모드 토글 버튼)
- C 섹션: 동시 보유 종목 한도 슬라이더 (1~20, default 5)
- D 섹션: 거래 빈도 슬라이더 (분당 default 3 / 일별 default 50)
- 하단: "기본값으로 초기화" 버튼 + "설정 저장" 버튼
- 데이터 없음 시: skeleton loader 표시 후 default seed 폼 값 표시
- AppHeader: "리스크 설정" 메뉴 활성(배경 gray-800 + 흰 텍스트)

## Screen 2 — /risk-events (위반 이력 페이지)

- 페이지 타이틀 "리스크 위반 이력" + 설명 문구
- 판정 필터 버튼 행: 전체 / 허용 / 차단 / 자동 정지
- 이벤트 0건 시: "리스크 위반 이력이 없습니다." + 안내 문구 표시
- 이벤트 존재 시: 테이블 (시각·규칙·판정·사유·시그널 링크) + 더 보기 버튼
- RiskEventBadge: ALLOWED=녹색, BLOCKED=빨강, AUTO_PAUSED=회색

## Screen 3 — /positions (포지션 페이지)

- 페이지 타이틀 "보유 포지션" + 설명 문구 + 새로고침 버튼
- 소스 필터 버튼 행: 전체 / MOCK / REAL
- 포지션 0건 시: "보유 포지션이 없습니다." + 안내 문구
- 포지션 존재 시: PositionCard 그리드 (code·수량·평균매수가·소스 배지·진입 시각)
- REAL 포지션: amber 배지 / MOCK 포지션: blue 배지

## STOMP 토스트 — useStompRisk

- BLOCKED 이벤트 도착: 빨간 토스트 "[차단] {reason}" 우측 하단 slide-in
- AUTO_PAUSED 이벤트 도착: 주황(warning) 토스트 "[자동 정지] {strategyName} — {reason}"
- 4초 후 자동 소멸 / ESC 전체 닫기 동작 확인
