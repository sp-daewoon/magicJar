# 화면 구성 설명 — 발굴 → MOCK 페이퍼 트레이딩 (ADR 0122 R3)

작성: 2026-06-10, frontend. 실제 스크린샷은 qa Visual(Playwright) 캡처.

## 1. 단타 발굴 화면 — 페이퍼 승급 확장 (`/strategy/daytrade-discover`)

기존 발굴 TOP N 화면에 add-only 보강.

- **헤더**: 우측 상단 "모의 트레이딩 대시보드 →" 링크(amber 톤) 추가.
- **후보 리스트 위 승급 툴바**(특정 프리셋 선택 시만 = `selectionMode`):
  - 좌: `PaperBadge`("모의 · 실거래 아님") + "후보를 선택해 모의(페이퍼)로 묶어 굴려볼 수 있습니다. (N종목 선택)" 안내.
  - 우: "모의로 굴려보기" 버튼(amber) — 1종목 이상 선택 시 활성.
  - '전체(합집합)' 모드(presetKey=null)면 "특정 프리셋을 선택해 주세요" 안내 + 버튼 비활성(단일 setup으로 묶을 수 없음).
- **후보 테이블**(`DaytradeMatchTable`): selectionMode면 맨 앞에 체크박스 컬럼. 선택 row는 amber 음영. 기존 rank·종목·점수·구성·펼침·관심종목 추가는 그대로.
- **승급 확인 모달**(`PaperPromoteModal`): 우상단 모의 배지 + setup 설명 + 선택 종목 칩 목록 + 가상 자본 입력(빈 값이면 기본 ₩10,000,000) + 취소/"모의로 굴려보기". 성공 시 토스트(전략 id·종목 수·가상 자본) + 선택 초기화.

## 2. 모의 트레이딩 대시보드 (`/strategy/paper`)

신규 페이지. AppHeader 전략 그룹 "모의 트레이딩" 진입.

- **헤더**: "모의 트레이딩" + `PaperBadge(md)`. 단타 발굴 링크 안내.
- **격리 배너**(`PaperIsolationBanner`): "모의(페이퍼) 트레이딩 — 실거래 아님" + 가상 자본·MOCK 강제·실 계좌 미영향 설명(amber).
- **활성 모의 전략 섹션**: 전략 카드(presetTitle + 모의 배지·전략 id/presetKey·종목 칩·가상 자본 `가상 ₩`·status badge·인터벌·"전략 중단" 버튼). 빈 시 "활성 모의 전략이 없습니다" + 발굴 안내. 로딩/에러 분기.
- **모의 포지션 섹션**: 모의 배지 + 표(종목·수량·평단(가상)·회차·실현손익(가상, +/- 색)·상태(보유/청산)). 빈 시 "모의 포지션이 없습니다" + 실 시세 기반 실제 시뮬 안내(mock 아님). 로딩/에러 분기.

## 모의 배지 UX LOCK (§6)

- `PaperBadge` "모의 · 실거래 아님" amber 칩을 전략·포지션·승급 모달·툴바 전부에 일관 적용.
