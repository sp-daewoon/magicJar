# 리스크 한도 사용량 게이지 4종 화면 설명

날짜: 2026-06-16
브랜치: agent/frontend/risk-usage-display
URL: http://localhost:5173/risk-config
데이터 소스: GET /api/risk/usage?userId=&strategyId= (backend 신설, 미머지 상태 — 배포 후 통합)

## 레이아웃 개요

기존 "리스크 설정" 폼(RiskConfigForm 카드 A~D, 디자인 무변경) **아래에**
"한도 사용 현황" 섹션이 추가된다.

- 섹션 헤더: "한도 사용 현황" + "10초마다 자동 갱신 · 설정 저장 시 즉시 반영"
- 우상단: 갱신 시각(`갱신 13:42:05`) / fetch 중이면 "갱신 중…"
- 카드 4종을 2열 그리드(sm:grid-cols-2)로 배치

## 게이지 색상 규칙

- 0~70% : 초록(emerald)
- 70~90% : 노랑(amber)
- 90%+ : 빨강(red)
- 데이터 없음 : 회색 + 점선 박스 "데이터 없음 · 준비 중"

## 카드 A — 포지션 한도 (계좌 전체 공유)

- 부제: "계좌 전체가 공유하는 단일 풀 — 종목별 한도가 아닙니다."
- 게이지: 전체노출 / 총한도 (예 9,000,000원 / 10,000,000원 → 90% 빨강)
- 행: 남은 한도(1,000,000원), 예수금(3,000,000원), 실제 매수가능(1,000,000원, 강조)
- 각주: "총한도 = min(절대 10,000,000원, 순자산 10.0% = 10,000,000원)"

## 카드 B — 일일 손실 한도 (DLL)

- enabled=false → 점선 박스 "미설정 — DLL이 비활성화되어 있습니다."
- enabled=true → 게이지: 손실(32,000원) / 한도(100,000원) → 32% 초록
- 행: 오늘 실현손익(-32,000원, 빨강), 한도(100,000원), 남은 손실 여유(68,000원)
- 손익이 +면 초록, -면 빨강

## 카드 C — 동시 보유 종목

- 게이지: 보유 3 / 5종목 → 60% 초록
- 점 표시: ●●●○○ (보유=파랑, 여유=회색) — 한도 20 이하일 때만
- 행: 현재 보유(3 / 5종목), 추가 가능(2종목 더)

## 카드 D — 거래 빈도 (전략당)

- 우상단 드롭다운: 전략 선택(useStrategies, nameKo 우선)
- 미선택 시: "전략을 선택하면 빈도 사용량이 표시됩니다."
- 전략 없음: "등록된 전략이 없습니다."
- 선택 시:
  - 게이지 1: 오늘 38 / 50회 → 76% 노랑 + "오늘 남은 거래 12회"
  - 게이지 2: 이번 분 1 / 3회 → 33% 초록

## 저장 → 즉시 갱신 동작

설정 폼에서 한도를 바꾸고 "설정 저장"(또는 "기본값으로 초기화")을 누르면
RiskConfigForm.onSaved → useInvalidateRiskUsage가 risk-usage 쿼리를 무효화 →
게이지 분모(총한도/한도/limit)가 새 설정값으로 즉시 재조회·반영된다.
(자동 10초 polling과 별개로 사용자 저장 즉시 반영하는 핵심 UX)

## 상태별 표기 (mock 합성 0)

- 로딩: 카드 4개 자리에 pulse 스켈레톤
- 에러: 빨간 박스 "한도 사용량을 불러오지 못했습니다. 잠시 후 다시 시도됩니다."
- 응답/섹션 null: 해당 카드만 점선 "데이터 없음 · 준비 중"
