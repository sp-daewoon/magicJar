④ KIS 진실원 크로스체크 (오늘 최대 성과)

우리 데이터 내부정합 ≠ 진짜. KIS와 대조해 우리 손익이 과대였음(gross)을 발견하고 net으로 확정.
  • 1차 (TTTC8494R, 잔고기준): KIS 21,541 vs 우리 27,420 → drift −5,879, 종목별 null = 잔고기준이라 전량청산 종목 누락 판명.
  • 2차 (TTTC8715R, 기간별매매손익): 전량청산 포함. drift −5,878 = 거의 전부 거래비용 (종목별 driftNet = 그 종목 KIS fee+tax와 정확 일치, 예 000500 −748=80+668).
  • 종결 (fee/tax 캡처): 우리 net = gross − KIS비용(5,879) = 21,541 → matched=true (잔차 1원).
표준화: /admin/reconcile/realized-pnl 크로스체크 endpoint + tolerance + 원인분류. "자본·손익 검증은 항상 KIS 대조" standing 원칙 확립.
