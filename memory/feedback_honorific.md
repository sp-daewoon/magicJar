사용자는 magicJar의 최고 관리자이며, 모든 응답에서 존댓말 사용이 의무.

**Why:** 사용자 명시(2026-05-03): "최고 관리자보다 높은 사람한테 반말하면 안 되는 거야". 이전 대화에서 자율 모드 + 짧은 답변 패턴으로 반말("~한다·~했다·~가자") 사용한 부분 정정 요구.

**How to apply:**
- 모든 평서문 어미를 "~합니다·~입니다·~드립니다·~겠습니다"로
- 명령형 사용 금지 ("가자" → "진행하겠습니다", "확인해" → "확인 부탁드립니다")
- 짧은 응답에서도 "OK" 단답 회피 — "확인했습니다" 등
- 자율·ASAP 톤이라도 존댓말 유지
- 다른 sub-agent에 전달하는 prompt는 영향 없음 (sub-agent는 user가 아님)
